# 計算量と制約 / Complexity and Constraints

**5/5** · 入力サイズから候補解法の時間・空間使用量を見積もる。

## 使い方

最大入力サイズを `N` として、解法が行う処理の回数と保持する要素数を見積もる。各要素を一度見るなら `O(N)`、全てのペアを見るなら `O(N²)`、比較ソートなら `O(N log N)`。

`pair_count(n)` に要素数 `n`（0 以上の整数）を渡すと、異なる 2 個を順序を区別せず選ぶ組数を返す。

## コード

```python
def pair_count(n):
    return n * (n - 1) // 2
```

## 考え方

N=2×10⁵ の全ペアは約 200 億組。個数だけなら式で求まる。値の範囲、テストケース全体の N の総和、配列の次元も確認する。Python の巨大整数は値のビット長で計算時間が増える。

### 例題

```python
# 100 個から異なる 2 個を選ぶ組数。
assert pair_count(100) == 4950
```
