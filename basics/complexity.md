# 計算量と制約 / Complexity and Constraints

**5/5** · 入力サイズから候補解法の時間・空間使用量を見積もる。

## 使い方

単一ループは O(N)、全てのペアは O(N²)、比較ソートは O(N log N)。

## コード

```python
def pair_count(n):
    return n * (n - 1) // 2
```

## 考え方

N=2×10⁵ の全ペアは約 200 億組。個数だけなら式で求まる。値の範囲、テストケース全体の N の総和、配列の次元も確認する。Python の巨大整数は値のビット長で計算時間が増える。

### 例題

```python
# 100 個から異なる 2 個を選ぶ組数。
assert pair_count(100) == 4950
```
